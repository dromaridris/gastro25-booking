How it works

  1. Upload PDF — choose the file and click Run import job. Text is extracted automatically (native PDF text; OCR for scanned pages when pytesseract is installed).
  2. Staged for review — the system creates a Knowledge Library entry (status: review) with extracted text preview. The file is saved on the server.
  3. Approve — open Review queue, check the content, then click Approve & publish.

Status done means the file was uploaded and queued for review — it is not published yet.
